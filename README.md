## About The Project

## Details
### Database
The DBMS is PostgreSQL. Flyway is used for the database migrations.
### Authentication
Spring Security is used to handle authentication and authorization. JWT is used for stateless authentication. The access token is short-lived and the refresh token is long-lived. The refresh token is stored server-side and rotated with every refresh reqeust.
### Containerisation
Docker is used to containerize the application, for easy deployment.
### Documentation
Autogenerated API documentation using ReDoc and Github-Pages.

## Getting Started

### Prerequisites

* Docker 
* This project requires a `.env` file. Copy `.env.example` into `.env` and fill in the fields.

### Building and Running
* build
```sh
docker-compose up --build
  ```

* run
```sh
docker-compose up
  ```

## Usage
### Authentication
#### Sign up
```sh
curl -i -X POST "$BASE_URL/api/auth/signup" \
-H "Content-Type: application/json" \
-d '{
"username": "demo_user",
"email": "demo@example.com",
"password": "password123"
}'
```
#### Login
```sh
curl -s -X POST "$BASE_URL/api/auth/login" \
-H "Content-Type: application/json" \
-d '{
"username": "demo_user",
"password": "password123"
}'
```

Example response:

```json
{
"accessToken": "eyJhbGciOiJIUzI1NiJ9...",
"expiresIn": 1800000,
"refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
"refreshExpiresIn": 172800000
}
```
---

### Refresh tokens


```sh
curl -s -X POST "$BASE_URL/api/auth/refresh" \
  -H "Content-Type: application/json" \
  -d "{
    \"refreshToken\": \"$REFRESH_TOKEN\"
  }"
```

Example response:

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresIn": 1800000,
  "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
  "refreshExpiresIn": 172800000
}
```
---

### Error Examples

#### Unauthorized request

Valid JWT is mandatory

```sh
curl -i -X GET "$BASE_URL/api/exercises/custom"
```

Expected response:

```txt
401 Unauthorized
```
