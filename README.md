## About The Project

A multi-user gym tracker that allows users to track their workouts, exercises and progress. It also provides analytics on the user's performance and progress over time.

## Details
### Database
The DBMS is PostgreSQL. Flyway is used for the database migrations.
### Authentication
Spring Security is used to handle authentication and authorization. JWT is used for stateless authentication. The access token is short-lived and the refresh token is long-lived. The refresh token is stored server-side and can be revoked.
### Containerisation
Docker is used to containerize the application, for easy deployment.
### Documentation
Autogenerated API documentation using ReDoc and Github-Pages.


<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

* Docker 
* This project requires a `.env` file. Copy `.env.example` into `.env` and fill in the fields.

### Building and Running
* build
```sh
docker-compose up --build
  ```

* run
```sh
docker-compose up
  ```
